# Пайплайн рубрики автоновин @automoto.ua / automoto.com.lv

- `day.py` — рендер креативів (Playwright + Chrome, шрифти Roboto, Roboto Condensed, Caveat з github.com/google/fonts → ~/.fonts). Вміст новин — у словнику `N`, ринки — `MK`. Фото кладуться в `/home/claude/day/photos/`, логотипи поруч зі скриптом.
- `texts.py` — тексти постів для всіх мереж і збірка CSV для Publer (12 колонок, Media URL з raw.githubusercontent.com).
- Креативи дня: `YYYY-MM-DD/ua|lv/*.jpg`, CSV: `csv/YYYY-MM-DD/`.

Правила оформлення:
- Обкладинки чергуються темна / світла (шахівниця в сітці профілю). Слайди каруселі — того ж тла, що й обкладинка.
- Карусель: обкладинка, «Що відомо» (4 пункти), слайд з цифрою, фінальне питання до читача («А що виберете ви: …»). Без смуги «Збережіть пост» внизу.
- Сторіс: 2 на новину (обкладинка + головне), фінальна «Всі деталі — в профілі» без стрілок униз.
- Фото з Pexels не підписуються; фото виробника — «Фото: <бренд>».
- Без зайвих плашок на обкладинці.
